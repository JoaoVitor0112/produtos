# Gerenciador de produtos[terminal]
projeto realizado em grupos na sala de aula.
## Objetivo 
Compreender como funciona o trabalho em grupo em uma equipe de desenvolvedores, analista e testers.
## Componentes
### Lógica de Programação
Estamos desenvolvendo em grupos um algoritmo utilizando python 3.1x.
### Redes
Fazemos o "deplay" do código em uma máquina virtual-Ubuntu Server.
### Processo de Desenvolvimento de software
Registramos requisitos funcionais e não funcionais, realizamos testes e aprendemos sobre o básico de CI/CP.
